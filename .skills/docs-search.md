# Docs Search

## Description
Searches aem.live documentation and blogs for platform feature information, implementation guidance, and best practices.

## When to Use
- Looking for AEM implementation guidance
- Understanding platform features
- Finding best practices
- Troubleshooting issues
- Learning new capabilities

## Search Strategy

### Primary Sources
- **aem.live/docs**: Official documentation
- **aem.live/blog**: Latest updates and insights
- **Community forums**: Discord, Slack discussions
- **GitHub repositories**: Code examples and issues

### Search Techniques
- Use specific AEM terminology
- Include "aem.live" in search queries
- Search for "Edge Delivery Services"
- Look for "Franklin" references (legacy name)

### Common Search Patterns
```
"aem.live block development"
"edge delivery services best practices"
"franklin block patterns"
"aem.live performance optimization"
"helix project setup"
```

## Search Process

### 1. Define Search Intent
- What specific information is needed?
- What problem are you trying to solve?
- What level of detail is required?

### 2. Use Targeted Queries
- Start with broad concepts
- Narrow down to specific features
- Include version or date constraints
- Use technical terminology

### 3. Validate Information
- Check publication date
- Verify against current practices
- Cross-reference multiple sources
- Test recommendations
