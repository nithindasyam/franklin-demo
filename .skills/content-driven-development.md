# Content Driven Development

## Description
Orchestrates the complete development workflow for building or modifying blocks and codifies AEM's content-first philosophy by requiring test content before code.

## When to Use
- Building new blocks from scratch
- Modifying existing blocks
- Implementing content-driven features
- Following AEM best practices for block development

## Workflow

### 1. Content First
- Always start with creating test content in a document
- Define the content structure that authors will use
- Establish the author-developer contract
- Create realistic content examples

### 2. Content Modeling
- Use the Content Modeling skill to design effective content structures
- Consider author experience and ease of use
- Define clear content patterns and expectations

### 3. Block Implementation
- Use the Building Blocks skill for implementation
- Follow AEM JavaScript decoration patterns
- Apply CSS styling conventions
- Implement progressive enhancement

### 4. Testing and Validation
- Test with real content from step 1
- Validate author experience
- Ensure responsive design
- Check accessibility compliance

### 5. Documentation
- Document the block's purpose and usage
- Provide content examples
- Include author guidelines

## Progressive Disclosure
This skill coordinates other specialized skills:
- Content Modeling (for structure design)
- Building Blocks (for implementation)
- Block Inventory (to check existing solutions)

## Success Criteria
- Content structure is intuitive for authors
- Block works with realistic content
- Implementation follows AEM patterns
- Code is maintainable and extensible
