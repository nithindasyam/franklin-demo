+-------------+----------------------------------------------------------------------------------------+
| name        | Skills                                                                                 |
+-------------+----------------------------------------------------------------------------------------+
| description | A responsive grid of skill badges with optional icons. Displays skills in dark cards   |
|             | arranged in a 1/2/3 column grid based on viewport width.                               |
|             |                                                                                        |
|             | **Implementation**                                                                     |
|             |                                                                                        |
|             | This block uses a 2-column table with:                                                 |
|             | - First column: Skill name (displayed text)                                            |
|             | - Second column: Icon name (maps to /icons/{name}.svg)                                 |
|             |                                                                                        |
|             | **Available Icons**: java, javascript, html, css, docker, kubernetes, react, nodejs,   |
|             | mysql, git, aws, adobe, maven, eslint, jira, sonarqube, apache, api, code              |
|             |                                                                                        |
|             | **When to use**                                                                        |
|             | - To showcase technical skills or competencies                                         |
|             | - For portfolio or resume-style pages                                                  |
|             | - When you want visual icons alongside skill names                                     |
